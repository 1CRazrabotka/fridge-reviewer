## 📖 О проекте

**Ревизор холодильника** — это локальное AI-приложение, которое анализирует фотографии вашего холодильника с помощью мультимодальной нейросети и предоставляет:

- 🥦 Список распознанных продуктов с оценкой свежести
- 🍳 Персонализированные рецепты из доступных ингредиентов
- 💡 Практические советы по хранению продуктов

### 🎯 Ключевая особенность

Приложение работает **полностью локально** — данные не покидают ваш компьютер. Никаких API-ключей, никаких подписок, никаких ограничений.

## ✨ Возможности

### 🔍 Анализ изображений
- Распознавание продуктов на фото с помощью vision-модели
- Оценка свежести каждого продукта (свежее / среднее / испорчено)
- Цветовая индикация состояния продуктов

### 🍳 Генерация рецептов
- 3 персонализированных рецепта из распознанных продуктов
- Подробные списки ингредиентов
- Пошаговые инструкции приготовления

### 💡 Умные советы
- Рекомендации по хранению продуктов
- Практические советы для продления свежести

### 🔒 Приватность и безопасность
- **100% локальная обработка** — данные не отправляются в облако
- **Без API-ключей** — не нужна регистрация в сервисах
- **Без ограничений** — работайте столько, сколько нужно

---

## 🛠️ Технологии

### Backend
- **Python 3.10+** — основной язык
- **Ollama** — локальный запуск LLM
- **LLaVA / Qwen2-VL** — мультимодальные vision-модели

### Frontend
- **Streamlit** — веб-интерфейс
- **Pillow** — обработка изображений

### AI/ML
- **Vision Transformers** — анализ изображений
- **Prompt Engineering** — структурированный JSON-вывод
- **Error Handling** — отказоустойчивость при некорректных ответах модели

## 🚀 Быстрый старт

### Предварительные требования

- Python 3.10 или выше
- Ollama (локальный сервер для LLM)
- 8+ ГБ оперативной памяти (рекомендуется 16 ГБ)

### 1. Установка Ollama

Скачайте и установите Ollama с официального сайта:

**Windows / macOS / Linux:**
```bash
# Перейдите на https://ollama.com/download и скачайте установщик

2. Скачивание модели
Откройте терминал и выполните:
# Базовая модель (4.7 ГБ, рекомендуется)
ollama pull llava

# Или более умная модель (8 ГБ, если есть ресурсы)
ollama pull llama3.2-vision

# Или лёгкая модель (1.7 ГБ, для слабых компьютеров)
ollama pull moondream
3. Установка зависимостей
# Клонируйте репозиторий
git clone https://github.com/yourusername/fridge-reviewer.git
cd fridge-reviewer

# Создайте виртуальное окружение
python -m venv venv

# Активируйте окружение
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt

4. Запуск приложения
streamlit run main.py

Приложение откроется в браузере по адресу http://localhost:8501
